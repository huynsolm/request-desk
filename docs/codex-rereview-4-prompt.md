   - 작업을 다른 작업으로 전환(taskId 변경)할 때 이전 작업의 dirty 상태가 새 작업에 새어 들어가지 않는가? (패널은 key={taskId} 로 다시 만들어지지만 확인해줘.)
   - 상태(할 일/진행 중/완료)·완료 조건 편집에도 같은 "건드리지 않은 것은 덮어쓰지 않는다" 원칙이 지켜지는가?
